# Сайт MAMEN

Перед любой работой прочитай [`docs/PROJECT.md`](docs/PROJECT.md): там состояние проекта,
утверждённые решения, условия владельца и план следующего этапа. Полное ТЗ — в [`docs/TZ.md`](docs/TZ.md).

Коротко:

- Владелец не программист. Объясняй простым языком, не проси править код, отвечай по-русски.
- Работа идёт по этапам из ТЗ. После каждого этапа остановись и жди явного подтверждения.
- Содержимое сайта — только в `data/site.json`. Страницы `index.html`, `about/`, `contact/`, `404.html`
  собираются командой `node src/build.mjs`; руками их не править.
- В страницах действует строгая политика загрузки: без атрибута `style`, без встроенных скриптов,
  без внешних ресурсов. Шрифты, значки и фото лежат на самом сайте.
- Утверждённый дизайн не переосмыслять. Главную страницу без необходимости не менять.
- Ветка `main` публикуется сразу: отправка в неё меняет живой сайт https://only1mamen.github.io.
- Никаких платных сервисов, банковских карт и функций сверх ТЗ.
