# Как управлять сайтом MAMEN

Сайт управляется из админки с телефона, без Claude и без компьютера.

- Сайт: https://only1mamen.github.io
- Админка: https://only1mamen.github.io/admin/
- Ключ для входа: «Пароли» на iPhone (начинается с `github_pat_`). Вводится при каждом входе, никому не показывать.

## Как изменить сайт

1. Открыть админку в Safari, войти по ключу.
2. Выбрать вкладку: Главная, Ссылки, Релиз, About, Contact, Сайт, История.
3. Поменять нужное.
4. «Предпросмотр» — посмотреть результат. На сайт ничего не попадает.
5. «Опубликовать». Изменения появятся через 1–10 минут.

«↶ Отменить» возвращает на шаг назад. «Сохранить черновик» сохраняет правки в закрытое хранилище, чтобы продолжить позже.

## Новый релиз

1. Вкладка «Релиз», режим «Автоматически».
2. Обложка, название, дата и время выхода (пояс по умолчанию — Москва).
3. Ссылки на пресейв VK Музыки и Яндекс Музыки (кнопка без ссылки не показывается).
4. Мультиссылка «Слушать», когда она есть.
5. Проверить в предпросмотре оба состояния и опубликовать.

В момент выхода карточка сама переключится с пресейва на «Слушать».

## Если что-то пошло не так

- Опубликовал не то: «История» → «Открыть» у нужной версии → «Опубликовать».
- Публикация не прошла: сайт остался прежним, повторить.
- «Сайт изменился в другом месте»: сохранить черновик, обновить страницу админки, войти и опубликовать заново.
- Ключ потерян или истёк: github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens →
  Generate new token → Only select repositories: `ONLY1MAMEN.github.io` и `mamen-site-private` →
  Permissions → Contents: Read and write → Generate token → сохранить в «Пароли».
- Ключ мог попасть к чужим: там же нажать Delete у этого ключа и создать новый.
- Резервная копия: «Сайт» → «Скачать копию»; вернуть — «Восстановить из файла», затем «Опубликовать».
